##  Reflection

1. Why should developers use feature branches?
Developers use feature branches to work on new features or changes separately from the main branch without affecting the existing code. This allows multiple developers to work on different tasks at the same time.
2. What caused the merge conflict?
A merge conflict happens when two branches modify the same part of a file differently. Git doesn't know which version to keep, so a developer must resolve it manually.
3. How did GitHub help you resolve it?
GitHub showed where the conflict occurred and allowed us to compare the changes from both branches. We could then choose which changes to keep and resolve the conflict before merging.
4. Why are pull requests useful in teams?
Pull requests allow developers to review each other's code before merging it into the main branch. This helps find mistakes, discuss improvements and make sure the code works correctly before adding it to the project.
